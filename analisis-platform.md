# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript, dan TypeScript | C#, Java, C++, Python, dan JavaScript | Kotlin, Java, Swift, dan Dart |
| Arsitektur | Client-server, dengan aplikasi diakses melalui browser | Aplikasi berjalan pada sistem operasi komputer dan dapat menggunakan layanan server | Aplikasi berjalan pada perangkat mobile dan dapat menggunakan layanan server atau API |
| Cara distribusi | Melalui URL dan server web | Melalui installer, toko aplikasi desktop, atau paket aplikasi | Melalui Google Play Store, Apple App Store, atau distribusi APK pada Android |
| Keunggulan | Mudah diakses melalui browser, lintas platform, dan pembaruan dapat dilakukan di server | Dapat memanfaatkan sumber daya komputer dan menyediakan fitur yang terintegrasi dengan sistem operasi | Praktis, mudah dibawa, dan dapat memanfaatkan fitur perangkat seperti kamera, GPS, dan sensor |
| Keterbatasan | Bergantung pada browser dan koneksi jaringan untuk banyak fitur; akses perangkat tertentu dibatasi | Perlu memperhatikan kompatibilitas sistem operasi dan proses instalasi | Memiliki keterbatasan ukuran layar, baterai, sumber daya, dan kompatibilitas perangkat |
| Contoh aplikasi | Gmail, Google Docs, dan Google Maps versi web | Visual Studio Code, Microsoft Word versi desktop, dan VLC Media Player | WhatsApp, Google Maps, dan Spotify versi mobile |

## 2. Penjelasan Singkat

Platform Web merupakan platform yang memungkinkan pengguna mengakses aplikasi melalui browser. Pengembangan web umumnya menggunakan HTML untuk struktur halaman, CSS untuk tampilan, serta JavaScript untuk interaksi.

Platform Desktop merupakan platform yang menjalankan aplikasi pada sistem operasi komputer, seperti Windows, macOS, dan Linux. Aplikasi desktop dapat dirancang untuk memanfaatkan sumber daya komputer serta berintegrasi dengan sistem operasi.

Platform Mobile merupakan platform yang dirancang untuk perangkat seperti smartphone dan tablet. Pengembangan aplikasi mobile perlu mempertimbangkan ukuran layar, konsumsi baterai, serta fitur perangkat keras seperti kamera dan GPS.

Setiap platform memiliki keunggulan dan keterbatasan. Pemilihan platform harus disesuaikan dengan kebutuhan pengguna, fitur aplikasi, dan lingkungan tempat aplikasi akan dijalankan.
